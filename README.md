
# Task-Specific Ensemble Transfer Learning for Cancer Image Classification

This repository contains the source code and reproducibility materials
for the study:

Task-Specific EnsembleTransfer Learning for Multi-Domain Cancer Image Classification: A Comparative Evaluation Across MRI,Ultrasound,Endoscopy, and CT
## Datasets

1. Figshare Brain Tumor MRI
2. BUS-BRA breast ultrasound
3. GastroEndoNet endoscopy
4. IQ-OTH/NCCD lung CT

All datasets used in this study are publicly available and were not generated by the authors; no new data were collected. The datasets are: the Figshare Brain Tumor MRI dataset (Cheng, 2017), figshare, DOI 10.6084/m9.figshare.1512427 (CC BY 4.0); the BUS-BRA breast ultrasound dataset (Gomez-Flores et al., 2024), Zenodo, DOI 10.5281/zenodo.8231412 (CC BY); the GastroEndoNet endoscopy dataset (Bitto et al., 2025), Mendeley Data, DOI 10.17632/ffyn828yf4 (CC BY-NC); and the IQ-OTH/NCCD lung cancer dataset (Al-Yasriy and Al-Huseiny, 2023), Mendeley Data, DOI 10.17632/bhmdr45bh2. The train/validation/test partition indices used in each experiment are provided with the code (see Code Availability). There are no restrictions on access to these data.

## Reproducibility

The experiments use fixed random seeds and the dataset split
information is provided where permitted.

## Models

The repository contains the implementation of the models and
ensemble strategies used in the manuscript.

## Evaluation

Evaluation scripts reproduce the metrics, confusion matrices,
ROC curves, and other reported results.
