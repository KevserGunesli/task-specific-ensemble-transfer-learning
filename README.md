# task-specific-ensemble-transfer-learning
Reproducible code for task-specific ensemble transfer learning across four cancer image classification benchmarks.
# Task-Specific Ensemble Transfer Learning for Cancer Image Classification

This repository contains the source code and reproducibility materials
for the study:

Task-Specific EnsembleTransfer Learning for Multi-Domain Cancer Image Classification: A Comparative Evaluation Across MRI,Ultrasound,Endoscopy, and CT
## Datasets

1. Figshare Brain Tumor MRI
2. BUS-BRA breast ultrasound
3. GastroEndoNet endoscopy
4. IQ-OTH/NCCD lung CT

The datasets are not redistributed in this repository.
Instructions and official dataset sources are provided below.
- Figshare Brain Tumor MRI= https://www.kaggle.com/datasets/ashkhagan/figshare-brain-tumor-dataset
- BUS-BRA breast ultrasound= https://www.kaggle.com/datasets/orvile/bus-bra-a-breast-ultrasound-dataset  DOI=10.1002/mp.16812.
- GastroEndoNet endoscopy= https://data.mendeley.com/datasets/ffyn828yf4/3  DOI= 10.17632/ffyn828yf4.3
- IQ-OTH/NCCD lung CT= https://www.kaggle.com/datasets/hamdallak/the-iqothnccd-lung-cancer-dataset  DOI= 10.17632/bhmdr45bh2.4


## Reproducibility

The experiments use fixed random seeds and the dataset split
information is provided where permitted.

## Models

The repository contains the implementation of the models and
ensemble strategies used in the manuscript.

## Evaluation

Evaluation scripts reproduce the metrics, confusion matrices,
ROC curves, and other reported results.
